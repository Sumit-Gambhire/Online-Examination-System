About The Project

College Mini Project

The Online Examination System is a full-stack web application developed as an academic mini-project. It aims to simplify test administration, reduce manual grading overhead, and provide students with a modern, responsive testing environment.

Architecture & Technology Stack

  • Backend: Python 3 with Flask web framework
  • Database & ORM: SQLite 3 with Flask-SQLAlchemy (relational schema)
  • Authentication: Flask-Login with Werkzeug password hashing
  • Templates & UI: Jinja2 templating, Semantic HTML5, CSS3 Variables, Vanilla JavaScript
  • Icons: Font Awesome 6 (free web icon font)

Key System Modules

Student Module

View enrolled/active exams, take timed assessments, review automated evaluation scores and historical test submissions.

Faculty / Admin Module

Create and schedule tests, manage multiple choice question banks, configure pass marks, and monitor student performances.
